# 🚗 Nothingan Pri S.A. — Integral Vehicle Rental Platform (ERP & CRM)

Full-stack web management platform developed as part of the **Multiplatform Application Development (DAM)** intermodular project (Group 3 — Institut Nicolau Copèrnic, Terrassa).

## 📋 Project Overview
**Nothingan Pri S.A.** is a vehicle rental company operating in Terrassa for over 36 years. This platform replaces legacy manual processes with a centralized digital ERP & CRM system covering the complete rental lifecycle:
- **Client Portal:** User registration with ID/driver's license document upload, date/time vehicle catalog filtering, automated vehicle blocking upon reservation, booking history, and 5-star vehicle reviews.
- **Agent Control Panel:** Fleet management (CRUD, activation/deactivation), client registration & premium status upgrades, vehicle delivery checklists with photo evidence, and vehicle return inspections with automated deposit deduction calculations.
- **Administrator Panel:** Pending client validation workflow, role-based access control, system error logs, and client reservation/revenue reporting.

## 🛠️ Tech Stack
- **Backend:** Java, Spring Boot, Spring Data JPA, Spring Security
- **Frontend:** Thymeleaf, HTML5, CSS3, JavaScript
- **Databases:** MySQL (Relational business data) + MongoDB (Documents, inspection photos, notifications, logs)
- **Testing & Management:** JUnit 5, Jira (Scrum Sprints), Figma (UI/UX Prototyping), Git / GitLab / GitHub
